# 🌱 EcoNest — Sustainable Decision Assistant

> A web-based sustainability assistant that helps households understand their monthly consumption and make practical, environmentally responsible decisions.

## 🌍 About the Project

EcoNest is a **Sustainable Decision Assistant for Household Waste and Resource Consumption**.

The platform allows users to enter their **previous month's household consumption details** and receive suggestions based on their consumption patterns.

Instead of providing the same generic sustainability advice to everyone, EcoNest aims to connect a user's own consumption data with practical actions they can take in everyday life.

## 🎯 Problem Statement

People often want to live more sustainably but may not know:

- How their household consumption affects sustainability
- Which habits can be improved
- Where unnecessary consumption can be reduced
- What practical changes they can make in their daily lives

EcoNest addresses this problem by turning household consumption information into understandable insights and actionable sustainability suggestions.

## ✨ Key Features

### 📋 Monthly Consumption Input
Users can enter their household consumption details from the previous month.

### 📊 Consumption Analysis
The system analyzes the entered information to identify consumption patterns and areas that may require attention.

### 💡 Personalized Suggestions
EcoNest provides sustainability suggestions based on the user's submitted consumption data.

### ♻️ Waste Reduction
The platform encourages users to reduce unnecessary household waste and adopt more responsible consumption habits.

### 💧 Resource Conservation
Users receive practical suggestions related to reducing unnecessary use of resources such as water and electricity.

### 📈 Monthly Insights
Users can review their consumption information and understand areas where sustainable changes can be made.
